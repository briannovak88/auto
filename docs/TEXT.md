# Этап 3: написание и перевод текста

В разделе «Текст» доступны два режима:

- **Написание и редактирование** — обязательное задание, исходный материал
  необязателен. Можно подготовить письмо, переписать абзац или исправить стиль.
- **Перевод** — обязательный исходный текст, язык результата и необязательные
  пожелания к терминологии/стилю. Исходный язык определяет модель.

Результат появляется справа. Его можно редактировать и копировать; копируется
именно текущая версия с правками. Новый успешный запрос заменяет прежний
результат; перед заменой пользовательских правок появляется подтверждение.
При ошибке, отмене или тайм-ауте сохраняются оба редактора. Переключение вкладок
не теряет текст. При выходе из приложения редакторы не сохраняются на диск:
скопируйте нужный текст перед закрытием.

Задание передаётся модели обычной фразой, а язык результата — системной
инструкцией. Например: «Напиши небольшой тест на знание Python». Пустой
исходник при написании не превращается в JSON-заготовку. Если модель повторяет
служебную структуру запроса, программа показывает сообщение об ошибке и
сохраняет прежний результат. Полезный JSON, запрошенный пользователем, не
запрещён; это узкая проверка повторения запроса, а не оценка качества ответа.
Автоматической повторной отправки нет: следующий запрос запускает пользователь.

## Установка на Windows

Команды PowerShell выполняются в папке с `main.py`. Уже установленное
окружение не нужно пересоздавать. Этот блок выбирает `venv` или `.venv`:

```powershell
if (Test-Path ".\venv\Scripts\python.exe") {
    $pythonExe = ".\venv\Scripts\python.exe"
} elseif (Test-Path ".\.venv\Scripts\python.exe") {
    $pythonExe = ".\.venv\Scripts\python.exe"
} else {
    throw "Окружение venv/.venv не найдено рядом с main.py."
}
& $pythonExe -m pip install -r requirements.txt -r requirements-text.txt
& $pythonExe -m pip check
```

Новая библиотека — `httpx` с зависимостями. PyTorch/EasyOCR для раздела
«Текст» не нужны. Без `requirements-text.txt` приложение открывается,
а попытка запроса показывает инструкцию установки. OCR устанавливается
отдельно по [OCR.md](OCR.md).

## Локальный режим: Ollama

1. Установите Ollama с [официального сайта](https://ollama.com/download/windows).
   После установки откройте новый терминал, чтобы обновился PATH.
2. Скачайте модель и проверьте список:

   ```powershell
   ollama pull qwen2.5:3b
   ollama list
   ```

3. Убедитесь, что Ollama запущена. На Windows она обычно работает в фоне.
   Если сервис не запущен, выполните `ollama serve` в отдельном терминале
   и оставьте его открытым. Если порт уже занят работающей Ollama, второй
   сервер запускать не нужно.
4. В терминале проекта запустите `& $pythonExe main.py`.
5. Откройте «Текст». По умолчанию выбраны Ollama, адрес
   `http://127.0.0.1:11434` и модель `qwen2.5:3b`.
6. Для другой установленной модели поменяйте её имя в «Настройки…».

Ollama устанавливается отдельной программой, а не через pip. Скачивание
модели требует интернета, места на диске и может занять время. Во время
запроса приложение модели не скачивает. Используйте локально установленные
модели, не облачные модели Ollama. Приложение обращается к локальному сервису;
его собственные настройки хранения и работы контролируются Ollama.

Модель `3b` выбрана как сравнительно небольшой начальный вариант. Качество
перевода и скорость зависят от модели, оборудования и текста; проверьте имена,
числа, термины и факты. У более крупных моделей выше требования к памяти.
Ollama сама управляет CPU/GPU; галочка NVIDIA/CUDA в разделе OCR на неё не влияет.
Если при одновременном OCR и Ollama не хватает памяти GPU, завершите одну задачу
перед запуском другой. Общий планировщик GPU в этапе 3 не добавлен.

## Облачный режим

Поддерживается один настраиваемый адаптер OpenAI-совместимого Chat Completions API.
По умолчанию адрес `https://api.openai.com/v1`, модель `gpt-4.1-mini`.
Модель должна быть доступна вашему аккаунту; имя можно изменить в настройках.
Для стороннего совместимого API укажите его HTTPS-адрес до `/chat/completions`,
обычно заканчивающийся `/v1`. API должен поддерживать `messages`, `stream=false`,
`temperature`, `max_tokens` и текстовый `choices[0].message.content`.

Ключ берётся только из переменной окружения `OCTOPUS_TEXT_API_KEY`. Чтобы
ввести его без помещения буквального ключа в историю команд PowerShell:

```powershell
$secureKey = Read-Host "API-ключ провайдера" -AsSecureString
$env:OCTOPUS_TEXT_API_KEY = [System.Net.NetworkCredential]::new("", $secureKey).Password
& $pythonExe main.py
```

Запускайте приложение из этого же терминала. Переменная действует для его
процессов; уже запущенное приложение нужно перезапустить. Ключ не сохраняется
в настройках или репозитории. Приложение не использует ключи других программ
и не обращается к системному хранилищу: реализован вариант через окружение.

После выбора «Облако» и нажатия кнопки действия появится диалог с конечным
адресом, моделью и **полным набором сообщений**, включая системную инструкцию,
пожелания и исходный текст. Только «Отправить этот текст» запускает запрос.
Подтверждение требуется заново каждый раз; смена вкладки сама ничего не отправляет.
PDF, подписи, база авторов, старые результаты и другие файлы не прикладываются.
Запрос может тарифицироваться выбранным провайдером.

В обоих режимах запрещены автоматические перенаправления HTTP. Локальный
адрес ограничен localhost/127.0.0.1/::1; облачный — HTTPS. Прокси из окружения
не используются (`trust_env=False`), поэтому корпоративные прокси и частные CA
могут требовать отдельной доработки клиента. Проверка сертификатов не отключается.
При ошибке Ollama автоматического перехода в облако нет. Серверные тела ошибок
и ключи не записываются в журналы приложения.

## Передача из OCR

После распознавания нажмите **«Передать в „Текст“»**. Приоритет выбора:

1. Выделенный мышью фрагмент предпросмотра OCR.
2. Если выделения текста нет — выбранные файлы PDF/JPG/PNG в таблице, в исходном порядке.
3. Если файлы не выбраны — весь общий текст результата.

При выборе файла передаются распознанные страницы с обозначением границ.
Промежуточные ошибки страниц обозначаются текстом. Для частичных результатов
проверяйте итоговый статус OCR. Передаётся текст, а не вёрстка таблиц.

Если редактор уже содержит материал, приложение спросит о замене. Во время
активного текстового запроса перенос не заменяет исходник; повторите его после
завершения или отмены. Сам перенос остаётся локальным и не вызывает модель.

## Ограничения и отмена

- До **12 000 символов исходного текста** и **2 000 символов задания** за запрос.
  Большой материал нужно разделить вручную; автоматического обрезания или
  разбиения нет. Передача большого результата OCR также отклоняется с сообщением.
- Объём ответа модели ограничен 4096 токенами. Для Ollama запрашивается контекст
  16384 токена. Реальные ограничения и поддержка параметров зависят от модели.
  Лимит символов не является точным счётчиком токенов. Если провайдер сообщает
  об остановке по лимиту или другой необычной причине, результат сохраняется
  с предупреждением о возможной неполноте.
- Тайм-аут по умолчанию 180 секунд, настройка 1–600 секунд. Первая загрузка
  локальной модели может быть долгой. Индикатор показывает ожидание и прошедшее
  время, а не вымышленный процент генерации; потокового вывода текста пока нет.
- «Отменить» отменяет асинхронный клиентский запрос. Провайдер мог уже получить
  текст, продолжить вычисления или начислить оплату; отмена не отзывает отправку.
  Автоматических повторов запроса нет.
- При закрытии окна во время работы можно продолжить работу либо отменить
  запрос и дождаться завершения фоновых задач перед закрытием.

Настройки адресов/моделей/тайм-аута находятся в
`<папка данных>/text-settings.json`. Режим при каждом запуске — локальный.
Исходники, результаты и API-ключ не сохраняются в этот файл.

## Python API без интерфейса

```python
import asyncio
from text_engine import TextRequest, TextSettings, generate

result = asyncio.run(generate(
    TextRequest("translate", "Добрый день!", language="Английский"),
    TextSettings(),
))
print(result.text)
print(result.warning)
```

Для отмены создайте `asyncio.Task` и вызовите `task.cancel()`.
Для облака настройте `provider="cloud"`, окружение с ключом и явно передайте
`cloud_consent=True` **после получения согласия на конкретный материал и адрес**.

Для сборки exe установите `requirements-text.txt` в окружение сборки. Поскольку
httpx импортируется при запросе, при необходимости добавьте к команде PyInstaller
`--collect-all httpx --collect-all httpcore --collect-all anyio --collect-all certifi`.
Ollama и её модели остаются отдельной установкой, не частью exe.
