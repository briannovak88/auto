# Повторение служебного JSON вместо текста

В локальном режиме Ollama с `qwen2.5:3b` пользователь получил объект
`output_language/task/source` вместо теста на знание Python. При этом
поздравление с днём рождения генерировалось нормально. В прежней реализации
тело пользовательского сообщения представляло собой JSON с этими полями.
Точная причина выбора ответа моделью не установлена; убран фактор, который
мог побуждать небольшую модель продолжать служебный шаблон.

В `text_engine.py` задание на написание теперь передаётся прямой фразой.
Язык результата и правила выполнения находятся в системной инструкции;
исходный материал добавляется отдельным блоком только при его наличии.
Перевод также получает обычную инструкцию и дословный исходный материал.
HTTP API по-прежнему использует стандартный JSON-протокол сообщений.

Добавлена узкая проверка ответа: точная копия служебного объекта, списка
сообщений или полного запроса с разметкой исходника отклоняется с понятной
ошибкой. Исходник, задание и прежний результат остаются в редакторах.
Другой JSON и обоснованное совпадение ответа с исходником разрешены.
Проверка не гарантирует правильность содержания и не обнаруживает все
возможные варианты пересказа задания. Автоматические повторы отсутствуют;
новый облачный запрос по-прежнему требует согласия на конкретные сообщения.

Изменены `text_engine.py`, `tests/test_text.py`, `tests/test_text_gui.py`
и инструкция `docs/TEXT.md`. Зависимости не менялись.

Выполнены проверки:

```bash
QT_QPA_PLATFORM=offscreen ../automat-docs/.venv/bin/python -m unittest tests.test_text tests.test_text_gui -v
QT_QPA_PLATFORM=offscreen ../automat-docs/.venv/bin/python -m unittest discover -v
../automat-docs/.venv/bin/python -m compileall -q text_engine.py tests/test_text.py tests/test_text_gui.py
git diff --check
```

21 проверка текстового модуля прошла. Полный набор — 71 тест, все прошли.
Использованы имитации Ollama и облачного API: исходный случай, JSON в блоке
кода, повторение списка сообщений, полезный JSON, неизменённый перевод,
сохранность редакторов, повторный запуск и совпадение подтверждённых
облачных сообщений с отправленными.

Настоящая `qwen2.5:3b` в среде не запускалась: Ollama здесь не установлена.
На Windows после обновления нужно повторить запрос «Напиши небольшой тест
на знание Python», поздравление и перевод. Проверить, что справа появляются
вопросы/текст/перевод, а при повторении служебной структуры — ошибка без
замены прежнего результата. Качество содержания зависит от модели.
