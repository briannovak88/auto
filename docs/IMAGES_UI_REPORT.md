# Распознавание картинок и компактный интерфейс

## Изменения

| Файлы | Результат |
| --- | --- |
| `ocr_inputs.py`, `ocr_engine.py` | Общий пакет PDF/JPG/JPEG/PNG. Картинка — одна страница, нормализация EXIF, белый фон для прозрачности, ограничение размера без изменения оригинала. Общие отмена, прогресс, DOCX и восстановление таблиц сохранены. |
| `ocr_widget.py`, `ocr_worker.py` | Выбор смешанных форматов и перетаскивание локальных файлов в список. Дубликаты, папки и сетевые URL не добавляются; во время обработки загрузка заблокирована. Сообщения воркера учитывают картинки. |
| `main.py` | Убран интерфейс PFX/ЭЦП и столбец творческого вклада. Поле вклада справа сохранено, существующие PFX-ссылки/файлы не удаляются. Уплотнены обе вкладки документов, выбор папок генерации размещён в одну строку. Значок окна постоянный. |
| `ui_shell.py` | Баннер 72 вместо 124 px; компактные отступы, поля, кнопки и макеты разделов. Постоянный осьминог в левой панели и общая функция значка приложения. |
| `icon.ico`, `assets/octopus.png` | Новый знак осьминога. ICO содержит размеры 16, 24, 32, 48, 64, 128 и 256 px; PNG — 512×512. |
| `requirements-ocr.txt` | Pillow объявлен явно; раньше он устанавливался как зависимость EasyOCR. |
| `tests/test_ocr_images.py`, `tests/test_ocr_gui.py`, `tests/test_gui.py` | Проверки новых форматов, перетаскивания, неизменности иконки, удаления элементов интерфейса и сохранности старых данных. Проверка размещения всех экранов без прокрутки страницы. |
| `README.md`, `docs/OCR.md`, `docs/TEXT.md`, `docs/previews/*.png` | Инструкции, ограничения форматов, сборка с иконкой и актуальные снимки на синтетических данных. |

## Выполненные проверки

```bash
QT_QPA_PLATFORM=offscreen ../automat-docs/.venv/bin/python -m unittest tests.test_gui tests.test_ocr_gui tests.test_ocr_images -v
QT_QPA_PLATFORM=offscreen ../automat-docs/.venv/bin/python -m unittest discover -v
../automat-docs/.venv/bin/python -m compileall -q main.py ui_shell.py ocr_engine.py ocr_inputs.py ocr_widget.py tests
../automat-docs/.venv/bin/python -m pip check
git diff --check
```

**66 тестов прошли**, pip check не обнаружил нарушенных зависимостей.
Проверены смешанный пакет PDF/JPG/PNG, повреждённая картинка, неподдерживаемый
формат, EXIF-поворот, прозрачный PNG, предел 3500 px, отмена после картинки,
сохранение оригиналов, редактируемые таблицы с объединёнными ячейками из JPG/PNG.
Анимированный PNG отклоняется, чтобы не потерять кадры незаметно для пользователя.

Qt-события DragEnter/Drop отправлены в настоящий viewport таблицы:
проверены смешанные форматы, порядок, дубликаты, папка с расширением PNG,
ссылка HTTPS, повторный перенос и запрет переноса во время работы.

Обе вкладки документов и все семь разделов проверены при 1366×700,
1366×768 и 1920×1080 логических пикселей. Максимумы полос прокрутки
страниц равны нулю. Проверены постоянные пиксели значка окна, QApplication
и аватара во всех разделах. Длинные списки и редакторы сохраняют внутреннюю
прокрутку. Маленькие окна и увеличенный системный шрифт могут потребовать
резервной прокрутки форм.

Дополнительно выполнен реальный EasyOCR на CPU с локальными CRAFT/Cyrillic G2:
два искусственных изображения 1200×220 px, одно JPEG и одно прозрачное PNG,
с фразами `OCTOPUS IMAGE TEST` и `Проверка распознавания`. Включено сохранение
структуры. Обе фразы найдены в обоих результатах, создан общий DOCX,
2/2 страницы, 0 ошибок, 8,092 с. Это проверка коротких синтетических картинок,
не оценка скорости больших фотографий документов. Файлы проверки оставлены
вне репозитория; реальные пользовательские изображения не использовались.

## Проверка на Windows

1. Обновить файлы проекта, включая `icon.ico`, и при необходимости выполнить
   `venv\Scripts\python.exe -m pip install -r requirements-ocr.txt`.
2. Перетащить из Проводника вместе PDF, JPG и PNG. Проверить порядок,
   повторный перенос без дубликатов, распознавание, отмену и общий Word.
   Программу обычно следует запускать без прав администратора: Windows
   блокирует перетаскивание из обычного Проводника в приложение с повышенными правами.
3. Проверить фотографию с EXIF-поворотом и скан таблицы на реальных данных.
4. Переключить все разделы: значок осьминога должен оставаться в заголовке,
   панели задач и слева. Название раздела и баннер продолжают обновляться.
5. Проверить размещение полей при своём разрешении и масштабе Windows.
   В форме автора есть творческий вклад и PNG-подпись, но нет выбора ЭЦП.
6. Для exe использовать `--icon icon.ico --add-data "icon.ico;."`, как в README.
   При устаревшем значке закреплённого ярлыка закрепить обновлённый exe заново.

Windows, панель задач Windows, сборка exe, Word/COM и NVIDIA в Linux-среде
не проверялись. Проверены Qt offscreen, сам ICO и реальная CPU-модель OCR.
